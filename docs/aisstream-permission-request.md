> We are building Port of Call, a free, publicly distributed TRMNL community recipe. A single shared server subscribes to AISStream for thirteen reviewed harbor areas, primarily in the US and Europe. Users do not receive an API key or open their own connections.
>
> The service caches latest positions for up to one hour of display eligibility and static ship metadata for up to seven days. It serves bounded public JSON snapshots (at most forty vessel markers) for map displays refreshed every fifteen minutes. It does not distribute the raw stream, sell data or construct historical vessel tracks. Separately sourced optional reference facts use Wikidata CC0.
>
> May we use AISStream data for this server-side cache, public JSON snapshots, rendered screens and recipe screenshots? Please confirm any required attribution, restrictions on caching/redistribution, retention obligations, usage limits or costs. We intend to use only the free service.
>
> Project: https://github.com/nikokoren/port_of_call
